# 坦克大战 · Tank Battle

经典红白机《Battle City》风格的网页坦克大战，纯 **HTML5 Canvas + JavaScript** 实现，零依赖、无需构建，浏览器打开即玩。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

也可以起一个本地静态服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |
| Enter | 开始 / 重新开始 |

## 玩法

- 控制己方坦克，消灭所有敌方坦克即可过关。
- 保护画面底部的**老鹰基地**，基地被摧毁则游戏结束。
- 己方共 3 条命，全部阵亡则游戏结束。
- 地形：**砖墙**可被子弹击毁，**钢墙**不可摧毁，**河流**坦克无法通过（子弹可穿过），**草丛**会隐藏坦克。

### 敌方坦克

| 类型 | 颜色 | 分值 | 特点 |
| --- | --- | --- | --- |
| 普通 | 灰色 | 100 | 标准速度 |
| 快速 | 绿色 | 200 | 移动更快 |
| 重装 | 红色 | 300 | 移动快、更高关卡出现 |

### 道具

击毁敌方坦克后有概率掉落，驾驶坦克拾取即可生效：

| 图标 | 名称 | 效果 |
| --- | --- | --- |
| ⭐ | 星星 | 升级火力（炮弹更快，最多可同时发射 2 发） |
| 🛡 | 头盔 | 获得 10 秒无敌护盾 |
| 🚙 | 坦克 | 增加 1 条命 |
| 💣 | 手雷 | 立即消灭场上所有敌人 |
| 🔧 | 铁铲 | 将基地周围砖墙暂时加固为钢墙 |
